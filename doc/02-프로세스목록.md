## 2. 세부 프로세스 정의

### 2.1 PROC-01: 압축파일 로드 및 가상 디렉토리 인덱싱 프로세스

#### 📊 시퀀스 다이어그램 (Mermaid)
```mermaid
sequenceDiagram
    autonumber
    actor User as 사용자
    participant UI as UI 화면 (DropZone/FilePicker)
    participant VFS as Archive Engine (VFS)
    participant Storage as IndexedDB (Archive Cache)

    User->>UI: 압축 파일 (ZIP, 7Z, RAR) 드래그 & 드롭 / 선택
    UI->>VFS: 파일 바이너리 핸들 전달 (Blob/File)
    Note over VFS: Central Directory / Header 바이트 블록 스캔
    VFS->>VFS: 오디오 파일 엔트리 필터링 (.mp3, .flac, .wav 등)
    VFS->>VFS: 가상 폴더/트랙 트리 인덱스 생성
    VFS->>Storage: 아카이브 메타데이터 및 VFS 인덱스 캐시 저장
    Storage-->>VFS: 저장 완료 응답
    VFS-->>UI: 디렉토리 트리 및 음원 트랙 목록 반환
    UI->>User: 플레이어 트랙 뷰어에 트리 및 파일 목록 렌더링
```

#### 📋 프로세스 단계 명세 (FORM-02-02)
| 단계 | 단계명 | 설명 | 관련 기능 ID |
| :---: | :--- | :--- | :---: |
| 1 | 파일 유입 감지 | FilePicker 또는 Drag & Drop 이벤트를 통해 로컬 압축 파일 스트림 객체 수신 | `FUNC-UI-001` |
| 2 | 헤더 바이트 스캔 | 전체 파일을 풀지 않고 끝단의 Central Directory 헤더만 부분 Range Read | `FUNC-ARCHIVE-001` |
| 3 | VFS 트리 생성 | 엔트리 목록 중 오디오 확장자 파일만 필터링하여 인메모리 트리 노드 구성 | `FUNC-ARCHIVE-001` |
| 4 | 인덱스 캐시 저장 | 생성된 VFS 파일 맵 정보를 로컬 IndexedDB에 캐싱하여 재진입 가속 | `FUNC-STORAGE-002` |
| 5 | 화면 목록 표출 | 가상 디렉토리 구조 및 음원 트랙 리스트를 UI 트랙 뷰어에 즉시 표시 | `FUNC-UI-001` |

#### ⚙️ 시스템 연동 영향도 (FORM-02-03)
| 단계 | 단계명 | 설명 | 관련 서브모듈 / SQL ID |
| :---: | :--- | :--- | :--- |
| 2~3 | 가상 인덱싱 | WASM 기반 고속 아카이브 헤더 스캐너 구동 | `ArchiveReader.wasm / CentralDirectoryParser` |
| 4 | 인덱스 캐싱 | 브라우저/로컬 스토리지에 아카이브 VFS 스키마 적재 | `IndexedDB: archive_index_store` |

### 2.2 PROC-02: 온디맨드 오디오 버퍼 스트리밍 및 재생 프로세스

#### 📊 시퀀스 다이어그램 (Mermaid)
```mermaid
sequenceDiagram
    autonumber
    actor User as 사용자
    participant UI as UI 플레이어 제어기
    participant Streamer as Archive Streaming Worker
    participant Audio as Web Audio Pipeline (DSP)
    participant Speaker as 오디오 하드웨어 (Output)

    User->>UI: 특정 음원 트랙 더블 클릭 (재생 요청)
    UI->>Streamer: 트랙 오프셋 및 압축 청크 요청
    Note over Streamer: 엔트리 데이터 스트림 부분 추출 (In-Memory)
    Streamer->>Audio: 오디오 바이너리 버퍼 (ArrayBuffer) 전달
    Audio->>Audio: 오디오 코덱 PCM 디코딩 (AudioContext.decodeAudioData)
    Audio->>Audio: DSP 노드 체인 (EQ -> Gain -> Analyser) 연결
    Audio->>Speaker: PCM 오디오 신호 버퍼 재생 시작 (TTFP < 500ms)
    Audio-->>UI: 현재 재생 위치(TimeUpdate) 및 오디오 진폭 스트림 전송
    UI->>User: 프로그레스 바 갱신 및 비주얼라이저 실시간 파형 렌더링
```

#### 📋 프로세스 단계 명세 (FORM-02-02)
| 단계 | 단계명 | 설명 | 관련 기능 ID |
| :---: | :--- | :--- | :---: |
| 1 | 재생 이벤트 수신 | 사용자가 트랙을 선택하면 트랙 고유 식별자 및 아카이브 엔트리 오프셋 확인 | `FUNC-UI-001` |
| 2 | 메모리 청크 추출 | 디스크 파일 I/O 없이 해당 트랙의 압축 바이트 블록만 Worker 스레드에서 추출 | `FUNC-ARCHIVE-002` |
| 3 | PCM 오디오 디코딩 | 수신된 ArrayBuffer를 Web Audio API 컨텍스트에서 즉각 PCM 버퍼로 디코딩 | `FUNC-AUDIO-001` |
| 4 | DSP 노드 체이닝 | 볼륨 노드, 10밴드 EQ 필터, 스펙트럼 분석기(AnalyserNode)에 연결 | `FUNC-AUDIO-002`, `FUNC-AUDIO-003` |
| 5 | 실시간 사운드 출력 | 오디오 하드웨어로 출력 개시 및 UI에 시간 업데이트 이벤트 브로드캐스팅 | `FUNC-AUDIO-002` |

#### ⚙️ 시스템 연동 영향도 (FORM-02-03)
| 단계 | 단계명 | 설명 | 관련 서브모듈 / SQL ID |
| :---: | :--- | :--- | :--- |
| 2 | 메모리 스트리밍 | 백그라운드 Worker 스레드 비동기 압축 해제 | `Worker: ArchiveStreamWorker.js` |
| 3~4 | Web Audio DSP | AudioContext 버퍼 디코딩 및 필터 그래프 연결 | `AudioEngine: WebAudioPipeline.ts` |

### 2.3 PROC-03: 메타데이터/가사/앨범아트 비동기 추출 프로세스

#### 📊 시퀀스 다이어그램 (Mermaid)
```mermaid
sequenceDiagram
    autonumber
    participant UI as UI 플레이어 화면
    participant TagEngine as Tag & Lyrics Parser
    participant VFS as Archive Engine (VFS)
    participant Cache as Blob Cache Storage

    UI->>TagEngine: 재생 대상 트랙 메타데이터 파싱 요청
    TagEngine->>VFS: 트랙 헤더/푸터 바이트 (ID3/Vorbis 청크) 조회
    VFS-->>TagEngine: 바이너리 청크 반환
    TagEngine->>TagEngine: ID3v2 / FLAC 태그 파싱 (곡명, 아티스트, 앨범명)
    alt 내장 앨범아트(APIC) 존재
        TagEngine->>Cache: 이미지 바이트 -> Blob URL 생성 및 캐싱
    else 동일 폴더 내 cover.jpg / folder.png 존재
        TagEngine->>VFS: 폴더 내 이미지 엔트리 추출 요청
        VFS-->>TagEngine: 이미지 바이너리 반환
        TagEngine->>Cache: Blob URL 캐싱
    end
    TagEngine->>VFS: 동명 .lrc 가사 파일 검색 및 타임스탬프 파싱
    TagEngine-->>UI: 정제된 메타데이터, 앨범아트 URL, 동기화 가사 배열 전달
    UI->>UI: 블러 배경 적용, 타이틀 변경, 가사 뷰어 동기화 렌더링
```

#### 📋 프로세스 단계 명세 (FORM-02-02)
| 단계 | 단계명 | 설명 | 관련 기능 ID |
| :---: | :--- | :--- | :---: |
| 1 | 태그 청크 분석 | 음원 파일의 헤더(ID3v2) 또는 푸터(ID3v1) 바이트 블록만 우선 읽기 | `FUNC-TAG-001` |
| 2 | 메타정보 파싱 | UTF-8/EUC-KR 인코딩을 판별하여 타이틀, 아티스트, 앨범 정보 파싱 | `FUNC-TAG-001` |
| 3 | 앨범아트 캐싱 | 내장 APIC 이미지 또는 동봉 커버 이미지를 추출하여 메모리 Blob URL 생성 | `FUNC-TAG-002` |
| 4 | 가사 타임라인 파싱 | `.lrc` 파일의 `[00:12.34]` 타임스탬프를 초 단위 인덱스로 파싱하여 배열화 | `FUNC-TAG-003` |
| 5 | UI 동적 바인딩 | 추출된 정보를 플레이어 메인 뷰, 앨범아트 블러 배경, 가사 창에 반영 | `FUNC-UI-001` |

### 2.4 PROC-04: 플레이리스트 큐 관리 및 연속 재생 프로세스

#### 📊 시퀀스 다이어그램 (Mermaid)
```mermaid
sequenceDiagram
    autonumber
    actor User as 사용자
    participant Audio as Web Audio Pipeline
    participant Queue as Playlist & Queue Manager
    participant UI as UI 플레이어 제어기
    participant Storage as IndexedDB (Playlist Store)

    Audio->>Queue: 트랙 재생 완료 이벤트 (onEnded) 발생
    Queue->>Queue: 재생 모드 판별 (순차 / 한곡반복 / 셔플 무작위)
    alt 셔플 모드
        Queue->>Queue: Fisher-Yates 알고리즘으로 다음 인덱스 계산
    else 한곡 반복
        Queue->>Queue: 동일 트랙 인덱스 유지
    else 전곡 반복 / 순차
        Queue->>Queue: 다음 트랙 인덱스 (Index + 1) 계산
    end
    Queue->>UI: 다음 재생 트랙 ID 통보 및 큐 UI 활성화
    Queue->>Storage: 현재 재생 상태 및 마지막 큐 상태 저장
    UI->>Audio: PROC-02 오디오 스트리밍 파이프라인 트리거
```

### 2.5 PROC-05: 10밴드 EQ 및 DSP 오디오 필터링 프로세스

#### 📊 시퀀스 다이어그램 (Mermaid)
```mermaid
sequenceDiagram
    autonumber
    actor User as 사용자
    participant UI as EQ 설정 UI
    participant DSP as Web Audio DSP Node Chain
    participant Analyser as AnalyserNode (FFT)
    participant Canvas as UI 비주얼라이저

    User->>UI: 특정 주파수 밴드 게인 조정 (예: 60Hz +4dB) / 프리셋 선택
    UI->>DSP: 밴드 주파수(Frequency) 및 Gain(dB) 값 전달
    DSP->>DSP: BiquadFilterNode.gain.setValueAtTime() 부드러운 전환 적용
    DSP->>Analyser: 필터링된 PCM 신호 통과
    Analyser->>Canvas: 주파수 스펙트럼 데이터(ByteFrequencyData) 전달
    Canvas->>Canvas: 60fps 부드러운 스펙트럼 바/파형 렌더링
```
