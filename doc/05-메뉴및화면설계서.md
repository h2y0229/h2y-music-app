# 05. 메뉴및화면설계서 (Menu & UI Specification)

> **상세설계 정의서**: 시스템의 정보 구조(Information Architecture, IA)인 메뉴 트리와 권한별 라우팅을 정의하고, 사용자 접점이 되는 전수 화면/팝업의 레이아웃, 와이어프레임(Wireframe), 그리드/폼 명세 및 UI 디자인 시스템 표준을 종합 설계합니다.

---

## 1. 메뉴 구조도 (Information Architecture, IA)

```mermaid
graph TD
    ROOT["🎵 h2y Music Player (Cross-Platform)"]
    ROOT --> M1["1. 재생 관제 (PLAY)"]
    ROOT --> M2["2. 아카이브 VFS (ARCHIVE)"]
    ROOT --> M3["3. 오디오 설정 (AUDIO)"]

    M1 --> M1_1["Now Playing 메인 뷰\n(/now-playing)"]
    M1 --> M1_2["동기화 LRC 가사 뷰\n(/lyrics)"]
    
    M2 --> M2_1["가상 트랙 목록\n(/tracks)"]
    M2 --> M2_2["압축 아카이브 선택\n(/open-archive)"]
    M2 --> M2_3["재생 대기열(Queue)\n(/queue)"]

    M3 --> M3_1["10밴드 그래픽 EQ\n(/equalizer)"]
    M3 --> M3_2["재생 속도 및 사운드 설정\n(/settings)"]
```

| **보관함** | 트랙 목록 | 음원 검색 및 필터 | `MENU-ARCHIVE-01` | `PAGE-TRACK-01` | `/tracks` | 전체 사용자 | **사용** |
