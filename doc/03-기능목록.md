# 03. 기능목록 (Functional Specification)

> **기능 마스터 정의서**: 개발 대상 기능을 대/중/소분류 체계로 분류하고 고유 기능 ID(`FUNC-*`)를 부여하여 전체 개발 범위를 체계적으로 정의합니다.

---

## 1. 제품군 및 모듈별 기능 요약 (FORM-03-01)

| 대분류 (제품군) | 중분류 (모듈) | 기능 ID 범위 | 세부 기능 수 | 핵심 역할 및 수검 범위 |
| :---: | :---: | :---: | :---: | :--- |
| `MUSIC` | `ARCHIVE` | `FUNC-ARCHIVE-001 ~ 004` | 4 | 압축 아카이브 헤더 스캔, 가상 디렉토리(VFS), 온디맨드 메모리 스트리밍 |
| `MUSIC` | `AUDIO` | `FUNC-AUDIO-001 ~ 004` | 4 | Web Audio 기반 멀티 코덱 PCM 디코딩, 재생 제어, 10밴드 EQ 및 지연시간 최적화 |
| `MUSIC` | `TAG` | `FUNC-TAG-001 ~ 003` | 3 | ID3/Vorbis/FLAC 메타데이터 파싱, 앨범아트 비동기 추출, 동기화 LRC 가사 뷰어 |
| `MUSIC` | `STORAGE` | `FUNC-STORAGE-001 ~ 002` | 2 | 재생목록 큐 및 셔플 알고리즘, IndexedDB 기반 로컬 데이터 영속화 |
| `MUSIC` | `UI` | `FUNC-UI-001 ~ 003` | 3 | Glassmorphism 다크 테마 UI, 키보드/미디어 세션 단축키, 크로스 플랫폼 빌드 |
| **합계** | **5개 모듈** | - | **16개 세부 기능** | **압축 음원 스트리밍 재생 플랫폼 전 영역** |

## 2. 세부 기능 목록 명세 (FORM-03-02)

| 모듈 | 기능 ID | 기능 구분 | 기능명 (Feature) | 상세 기능 설명 |
| :---: | :---: | :---: | :--- | :--- |
| `ARCHIVE` | `FUNC-ARCHIVE-001` | 신규 | 아카이브 헤더 파싱 및 VFS 인덱싱 | 전체 압축 해제 없이 ZIP, 7Z, RAR, TAR 헤더(Central Directory)를 스캔하여 가상 파일 트리 구조 구축 |
| `ARCHIVE` | `FUNC-ARCHIVE-002` | 신규 | 온디맨드 청크 메모리 스트리밍 | 선택된 오디오 트랙의 바이너리 청크만 Worker 스레드에서 메모리로 부분 압축 해제하여 버퍼 제공 |
| `ARCHIVE` | `FUNC-ARCHIVE-003` | 신규 | 대용량 아카이브 메모리 최적화 | 10GB 이상(1,000트랙 이상) 파일 처리 시 인덱스 메모리를 슬림화(150MB 이내)하고 미사용 버퍼 자동 GC |
| `ARCHIVE` | `FUNC-ARCHIVE-004` | 신규 | 손상/암호화 아카이브 예외 처리 | 암호화된 ZIP, 손상된 CRC 블록, 미지원 아카이브 유입 시 시스템 중단 방지 및 친화적 에러 메시지 알림 |
| `AUDIO` | `FUNC-AUDIO-001` | 신규 | 멀티 코덱 PCM 디코딩 | MP3, FLAC, WAV, AAC, OGG, M4A 오디오 바이너리를 Web Audio API 및 WASM 디코더로 PCM 변환 |
| `AUDIO` | `FUNC-AUDIO-002` | 신규 | 고정밀 재생 파이프라인 제어 | 재생, 일시정지, 밀리초 단위 정밀 탐색(Seek), 볼륨 로그 감쇠, 재생 속도(0.5x~2.0x) 제어 |
| `AUDIO` | `FUNC-AUDIO-003` | 신규 | 10밴드 그래픽 EQ 및 DSP 필터 | BiquadFilter 노드 체인(32Hz, 64Hz, 125Hz, 250Hz, 500Hz, 1kHz, 2kHz, 4kHz, 8kHz, 16kHz) 및 프리셋 제공 |
| `AUDIO` | `FUNC-AUDIO-004` | 신규 | 초저지연 재생 최적화 (TTFP) | 청크 스트림 선행 로딩(Pre-buffering) 기법을 통해 재생 클릭 후 첫 오디오 출력까지 500ms 미만 보장 |
| `TAG` | `FUNC-TAG-001` | 신규 | 멀티 포맷 메타데이터 파서 | ID3v1/ID3v2, Vorbis Comment, FLAC Header에서 곡명, 아티스트, 앨범, 트랙 번호, 장르 정보 파싱 |
| `TAG` | `FUNC-TAG-002` | 신규 | 앨범 커버아트 비동기 추출 | 음원 내장 APIC 이미지 및 아카이브 내 동봉 커버 이미지(cover.jpg 등) 추출 후 Blob URL 캐시 생성 |
| `TAG` | `FUNC-TAG-003` | 신규 | 실시간 동기화 가사 파서 | 동봉된 `.lrc` 파일 및 내장 USLT 가사 데이터를 파싱하여 재생 시간에 맞추어 실시간 가사 하이라이트 |
| `STORAGE` | `FUNC-STORAGE-001` | 신규 | 재생목록 큐 및 스마트 셔플 | 트랙 대기열 추가/삭제/드래그 정렬 및 Fisher-Yates 기반 셔플, 한곡/전곡 반복 모드 지원 |
| `STORAGE` | `FUNC-STORAGE-002` | 신규 | IndexedDB 상태 영속화 | 최근 재생 목록, 마지막 재생 위치, 사용자 EQ 프리셋, 즐겨찾기 목록을 로컬 브라우저 DB에 안전하게 저장 |
| `UI` | `FUNC-UI-001` | 신규 | Glassmorphism 반응형 플레이어 UI | 앨범아트 연동 동적 블러 배경, 실시간 60fps 오디오 스펙트럼 비주얼라이저, 반응형 3단 레이아웃 |
| `UI` | `FUNC-UI-002` | 신규 | 미디어 단축키 & OS 미디어 세션 | 스페이스바(재생/정지), 방향키(탐색/볼륨), OS 키보드 미디어 키 및 시스템 알림창 Now Playing 연동 |
| `UI` | `FUNC-UI-003` | 신규 | 크로스 플랫폼 패키징 배포 | Electron / Web 번들링 파이프라인을 구축하여 macOS, Windows, Web 환경에서 일관된 실행 보장 |
